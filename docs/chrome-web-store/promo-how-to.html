How to use in 3 steps

The local demo site ships disable-devtool. With the extension off, opening DevTools blanks the page. Turn the toggle on, and you can inspect it normally.

  1. Open the page with unlock off → press F12 → blank page
  2. Click the toolbar icon and check Enable unlock for this site
  3. After reload, open DevTools again → content stays, Console shows the inject log
